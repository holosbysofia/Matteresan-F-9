HOLOS Matteresan • Felfinnaren
✅

Så kontrollerar jag mitt svar

Innan jag säger att jag är klar

1. Är svaret rimligt?

Stämmer storleken på svaret ungefär med vad jag förväntade mig?

2. Kan jag uppskatta?

Använd avrundning eller huvudräkning som kontroll.

3. Kan jag använda motsatt räknesätt?

Addition ↔ subtraktion
Multiplikation ↔ division

4. Kan jag lösa på ett annat sätt?

Två olika strategier som ger samma svar stärker kontrollen.

5. Har jag svarat på frågan?

Ett korrekt tal är inte alltid ett komplett svar.

6. Kan jag förklara?

Om jag kan förklara lösningen förstår jag den bättre.

Klar betyder: löst, förklarat och kontrollerat.
