Veckans problem

Ett problem • Många tankar • Flera vägar

Varje vecka möter du ett problem som är gjort för att diskuteras, undersökas och lösas på flera olika sätt.

💡 Här är tänkandet viktigast

Veckans problem handlar inte om att bli klar först. Du ska få tid att tänka, prova, rita, diskutera, jämföra lösningar och förklara varför din strategi fungerar.

Välj din nivå

Veckans problem finns i tre nivåområden med tydlig progression genom F–9.

🌱

Veckans problem F–3

Rita, bygg, prova och berätta. Problem med tal, former, mönster och vardag.

Så arbetar du med Veckans problem

Försök först själv och använd sedan samtalet för att utveckla din lösning.

1️⃣

Tänk själv

Läs problemet och ge dig själv tid att fundera.

2️⃣

Visa din idé

Rita, skriv, gör en tabell eller använd matematiska symboler.

3️⃣

Prata tillsammans

Jämför strategier och ställ frågor till varandra.

4️⃣

Utveckla

Förbättra din lösning efter att du hört andras idéer.

Problemtyper

Veckans problem kan se olika ut från vecka till vecka.

🔢

Talproblem

Tal, räknesätt, delbarhet, bråk, procent och talmönster.

📐

Geometriproblem

Former, vinklar, area, omkrets, volym, skala och konstruktion.

🔐

Logikproblem

Ledtrådar, systematiskt prövande och matematiska mysterier.

🧩

Mönsterproblem

Upptäck regler, fortsätt mönster och generalisera.

🌍

Verklighetsproblem

Ekonomi, resor, statistik, mätning och matematiska beslut.

🚀

Öppna problem

Problem med flera möjliga svar, strategier eller lösningsvägar.

🗣️ När ni delar lösningar

Samtalet efter problemet är en viktig del av lärandet.

🧠 Hur tänkte du?

Beskriv din strategi steg för steg.

🔄 Finns ett annat sätt?

Jämför din lösning med någon som tänkte annorlunda.

⚖️ Vilken strategi är effektiv?

Diskutera fördelar och nackdelar med olika lösningar.

✅ Hur vet vi?

Kontrollera lösningen och förklara varför den fungerar.

❓ Vad händer om...?

Ändra ett tal eller villkor och undersök hur problemet förändras.

🚀 Kan vi generalisera?

Försök formulera en regel eller slutsats som gäller i fler fall.
